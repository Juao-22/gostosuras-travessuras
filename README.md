# Viva Sua Profissão — Analista de Testes de Software (QA)

Portal informativo desenvolvido no Curso Técnico em Desenvolvimento de Sistemas para apresentar a carreira de **Analista de Testes de Software (QA)**, suas habilidades essenciais, mercado de trabalho, materiais gratuitos de estudo e boas práticas de desenvolvimento web.

## Estrutura do Projeto (`aa/`)

- `index.html` — Página inicial com introdução à carreira de QA e atividades do dia a dia.
- `pages/habilidades.html` — Competências técnicas (*Hard Skills*) e comportamentais (*Soft Skills*).
- `pages/materiais.html` — Panorama de mercado, níveis de senioridade e guias gratuitos recomendados.
- `pages/sobre.html` — Informações sobre o projeto, boas práticas aplicadas e seção de Perguntas Frequentes (FAQ).
- `css/style.css` — Design system responsivo (*mobile-first*), acessível e com suporte a modo claro/escuro.
- `js/theme.js` — Controle de alternância e persistência do tema claro/escuro.
- `img/` — Imagens otimizadas e logotipo vetorial (`logo-qa.svg`).
- `robots.txt` e `sitemap.xml` — Configurações de SEO técnico para indexação.
